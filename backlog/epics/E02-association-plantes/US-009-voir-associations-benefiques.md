## [US-009] Voir les associations bénéfiques d'une plante

**En tant que** jardinier,
**je veux** consulter quelles plantes s'associent bien avec une plante donnée,
**afin de** planifier des associations favorisant la croissance et réduisant les nuisibles.

### Critères d'acceptation

- [ ] CA1 : Depuis la fiche d'une plante, je vois la liste des plantes bénéfiques pour elle.
- [ ] CA2 : Pour chaque association, la raison est indiquée (ex. "repousse les pucerons", "fixe l'azote").
- [ ] CA3 : Je peux cliquer sur une plante associée pour accéder à sa propre fiche.
- [ ] CA4 : Si aucune association connue n'existe, un message neutre l'indique.

### Notes & contraintes
- Les données d'association proviennent d'une table pré-remplie (pas de contribution utilisateur dans cette version).
- Exemples clés : tomate + basilic, carotte + poireau, courge + haricot + maïs (trio des 3 sœurs).
