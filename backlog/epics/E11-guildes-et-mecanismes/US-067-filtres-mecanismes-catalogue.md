## [US-067] Filtres par mecanisme dans le catalogue

**En tant que** jardinier,
**je veux** filtrer le catalogue de plantes par mecanisme (fixation d'azote, repulsion ravageurs, etc.),
**afin de** trouver rapidement les plantes qui apportent un mecanisme specifique a ma guilde.

### Criteres d'acceptation

- [x] CA1 : Une ligne de chips de mecanisme apparait sous les tris existants dans le catalogue.
- [x] CA2 : Un clic sur un chip filtre le catalogue pour ne montrer que les plantes ayant ce mecanisme (intrinseque ou relationnel).
- [x] CA3 : Un second clic desactive le filtre.
- [x] CA4 : Le filtre se cumule avec les autres filtres existants (recherche, tri, "Mes plantes", enracinement).

### Notes & contraintes
- Filtrage purement cote client via les signaux existants.
