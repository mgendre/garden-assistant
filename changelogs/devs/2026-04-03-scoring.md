### Backend

- **Refonte du scoring dans `PlantAssociationService`** : les constantes de score ont ete ajustees — `NeutralScore` passe de 0.0 a 0.1, `UnknownScore` de -0.1 a 0.0. Nouveaux malus : `SameFamilyMalus` (-0.5) et `WaterIncompatibilityMalus` (-0.5)
- **Bonus plante centrale** : le endpoint accepte desormais `CentralPlantIds` dans `CompanionRecommendationRequest`. Une association avec une plante centrale recoit un bonus de +0.3
- **Bonus enracinement additif** : le bonus de profondeur racinaire passe de multiplicatif (x1.10) a additif (+0.1), et s'applique independamment de l'effet de l'association (meme sans association, la complementarite racinaire compte)
- **Malus famille et eau** : pour chaque plante selectionnee de meme famille botanique, -0.5. Pour chaque plante dont le `WaterNeeds` differe de 2+ niveaux, -0.5
- **Rating 1-5** : nouvelle methode `CalculateRating(double score)` — seuils : >=1.5 -> 5, >=1.0 -> 4, >0 -> 3, >=0 -> 2, <0 -> 1
- **Suppression de `PlantsToAvoid`** : le champ est retire de `CompanionSearchResultDto`. Toutes les plantes (y compris nefastes) sont dans `GoodCompanions` avec leur rating. La methode `BuildPlantsToAvoid` est supprimee
- **`CompanionRecommendationDto` enrichi** : ajout de `HarmfulMechanisms`, `Rating`, `Score`, `HasRootDepthBonus`, `HasSameFamilyMalus`, `HasWaterIncompatibility`
- **Nouvelle methode `CollectHarmfulMechanisms`** : collecte les mecanismes nefastes par candidat (symetrique de `CollectBeneficialMechanisms`)
- **Tri** : le tri primaire se fait par `Rating` descendant, puis par `Score` descendant, puis alphabetique
- **`IPlantAssociationService`** : signature mise a jour avec `centralPlantIds` optionnel
- **`PlantAssociationsController`** : passe `CentralPlantIds` au service

### Donnees (seeds)

- **76 nouvelles associations** dans `associations.json` (total ~445) : associations mediterraneennes (romarin/thym/lavande/sauge), engrais verts (vesce/trefle/seigle/avoine/luzerne), utilitaires (ortie/prele/achillee), Trois Soeurs (mais/haricot-a-rames/courge), Alliacees (ail/ciboulette), Brassicacees (chou/brocoli/chou-fleur + capucine/pois/thym)
- **Corrections tournesol** : `tournesol -> haricot` (Harmful) supprime, `tournesol -> laitue` et `tournesol -> betterave` passes de Harmful a Neutral
- **4 associations absinthe** ajoutees : epinard, mache, roquette, cerfeuil (Harmful, RootAllelopathy)
- **Roles centraux dans `guilds.json`** : les guildes Engrais Verts, Pollinisateurs, Plantes Utilitaires et Prairie Mellifere recoivent leurs plantes centrales au format `{ "key": "...", "role": "Central" }`

### Frontend

- **`CompanionStore`** : `avoidPlantIds` recalcule a partir de `rating === 1` dans `goodCompanions` (plus de `plantsToAvoid`). Le tri par compatibilite utilise `rating` + `score` au lieu de categories discretes. `getCompatibility()` retourne `'avoid'` pour rating 1, `'good'` pour rating >= 4. Le `minScore: 0` est retire de la requete API. `centralPlantIds` est envoye dans la requete
- **`PlantCatalogue`** : etoiles (1-5) affichees sous le bouton info via `.plant-rating`. Classes conditionnelles `compat-good` (rating >= 4), `compat-avoid` (rating === 1), `compat-central` (plante centrale). Nouvelle methode `getRating(plant)` et `openRatingDetail(plant, event)` ouvrant un `RatingDetailDialog`
- **`RatingDetailDialog`** : nouveau composant affichant le score, les mecanismes benefiques et nefastes sous forme de badges, et les modificateurs (bonus central, bonus racinaire, malus famille, malus eau)
- **`PlantAssociationPanel`** : nouveau computed signal `familyDiversityWarnings()` — alerte quand >= 3 plantes de la meme famille representent > 40% de la guilde. Badge `.health-badge--family` et bloc `.assistant-warning--family` ajoutes
- **Styles `_plant-list.scss`** : bordures simplifiees (plus de fond colore), bordure bleue (#3b82f6) pour les plantes centrales, `.plant-actions-col` pour empiler info + etoiles, `.plant-rating` avec variantes `--good` et `--avoid`
- **Styles `_plant-association-panel.scss`** : `.health-badge--family` (orange) et `.assistant-warning--family`
- **Traductions `fr.json`** : section `Rating` complete (13 cles) + `GuildAssistant.BadgeFamily`, `GuildAssistant.FamilyDiversityTitle`, `GuildAssistant.FamilyDiversityMessage`
- **API client** : `CompanionRecommendationDto` et `CompanionSearchResultDto` mis a jour (plus de `plantsToAvoid`, ajout des champs rating/score/flags)
