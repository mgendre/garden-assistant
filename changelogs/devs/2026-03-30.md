### Stack technique

- **Frontend :** Angular 21, Tailwind CSS v4, Angular Signals, ngx-translate (francais)
- **Backend :** .NET 10 / ASP.NET Core, Entity Framework Core code-first
- **Base de donnees :** PostgreSQL 17 avec convention snake_case
- **Authentification :** JWT (access token 15 min + refresh token 30 jours)
- **Conteneurisation :** Podman rootless, Podman Compose, Traefik en reverse proxy

### Backend

- 6 controllers API REST : `AuthController`, `PlantsController`, `PlantAssociationsController`, `UserPlantsController`, `GuildsController`, `CalendarController`
- Services avec interfaces : `PlantService`, `PlantAssociationService`, `GuildService`, `PlantActionService`, `HarvestReadinessService`, `UserPlantService`
- 26 entites EF Core, 12 enums pour le domaine (associations, mecanismes, actions culturales)
- Seed data complet pour le climat du plateau suisse

### Frontend

- Architecture par feature : `companions`, `guilds`, `calendar`, `my-plants`, `whats-new`
- Composants standalone avec lazy loading par route
- Gestion d'etat par Angular Signals et signal stores (`CompanionStore`, `GuildStore`, `CalendarStore`, `PlantStore`)
- Diagramme de Gantt pour le calendrier cultural avec filtres par type d'action
- Assistant de guildes : analyse des lacunes, diversite des familles, alertes d'associations nefastes
- Visualisation de la stratification racinaire

### Infrastructure

- Deploiement en un seul script (`hosting/start.sh`) via Podman Compose
- Support TLS via Let's Encrypt (Traefik)
- Multi-stage builds pour les images de production
